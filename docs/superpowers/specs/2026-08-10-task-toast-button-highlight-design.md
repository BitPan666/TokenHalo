# 任务胶囊主按钮高光设计

## 目标

保留“打开 Codex”按钮现有蓝色主体与胶囊形状，在顶部增加偏白、半透明的弧面高光，使按钮与整体玻璃浮层语言一致。

## 视觉方案

- 高光位于按钮上方约 35% 区域，从偏白的低透明度逐渐过渡到完全透明。
- 高光跟随胶囊圆角，不出现独立的白色条带或硬边界。
- 保留现有蓝色、白色文字和按钮尺寸；边框改为更轻的内部折射感。
- 增加极轻的底部深色内阴影，用于支撑体积感，不使用外发光。

## 交互与可用性

- hover 时只轻微提亮顶部高光，不改变布局。
- active 时高光稍弱，并保留轻微按压反馈。
- focus-visible 继续使用现有焦点轮廓。
- 文字与背景对比度不低于现有按钮。

## 范围

本次只调整 `.task-toast-primary`，同时覆盖任务胶囊和首次通知授权胶囊中的同类主按钮。不修改次要按钮、卡片布局、文案、动画时长或任务通知逻辑。

## 验证

- 在浅色胶囊背景上检查顶部高光是否柔和且可见。
- 检查默认、hover、active 和键盘聚焦状态。
- 确认两种使用位置的按钮尺寸与布局不变。
