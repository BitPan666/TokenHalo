# 展开卡片圆角统一设计

## 目标

将“剩余额度”和“本机 Token 统计”两张展开卡片的外层圆角统一为 `40px`。

## 实现范围

- 为两张展开卡片使用同一个外层圆角来源，避免以后分别修改导致不一致。
- 只调整卡片最外层轮廓。
- 不修改按钮、进度条、标签页、设置弹窗等内部元素的圆角。
- 不调整卡片尺寸、内边距、颜色、阴影或其他视觉参数。

## 验收标准

- `.quota-card` 的浏览器计算圆角为 `40px`。
- `.token-stats-card` 的浏览器计算圆角为 `40px`。
- 自动化测试能够在任一卡片偏离 `40px` 时失败。
- 前端完整测试和生产构建通过。
