# TokenHalo 卡片范围原生玻璃设计

## 目标

把当前 CSS 毛玻璃升级为 macOS 原生玻璃，同时避免此前“整个透明窗口出现矩形底板”的问题。最终效果必须满足：

- 玻璃只覆盖实际卡片，不覆盖透明窗口的空白区域。
- 收起悬浮球保持 `80×80`、四周 `10px` 留白、圆角 `28px`。
- 剩余额度卡片保持 `320×320`、圆角 `40px`。
- 本机统计卡片保持 `400×400`、圆角 `40px`。
- 悬停、闲置只影响交互，不再改变卡片透明度或模糊程度。
- 设置中保留透明度，新增玻璃样式，并把连续“背景模糊强度”改为弱、中、强三级“效果强度”。
- 原生能力不可用时自动回退到 CSS 玻璃，内容始终可读。

## 已确认的技术方案

### 原生视图层级

原生玻璃视图作为 `WKWebView` 的同级视图插入其下方：

```text
窗口内容容器
├── 原生玻璃视图
└── WKWebView（透明背景，负责所有内容与交互）
```

不得把 `WKWebView` 移入 `NSGlassEffectView.contentView`。项目已有契约测试继续阻止这种重挂载，因为它会破坏 WebKit 的窗口观察者清理并可能导致崩溃。

原生玻璃视图使用固定 tag 查找和更新。切换模式或更改外观设置时更新同一个视图；后端类型发生变化时先移除旧视图再创建新视图，避免玻璃层叠加。

### 系统版本与回退

- macOS 26 及以上：使用 `NSGlassEffectView`。
- 较早 macOS：使用 `NSVisualEffectView`。
- 创建或配置原生视图失败：返回 `CssFallback`，前端 CSS 背景继续负责可读性。

`NSGlassEffectView` 使用系统提供的动态玻璃渲染。macOS 26.5 AppKit 的公开
`NSGlassEffectView` 接口不提供交互开关，因此不调用私有或不存在的 selector，也不在 UI
中提供相关选项。玻璃样式映射为：

- 清透：`NSGlassEffectViewStyleClear`
- 标准：`NSGlassEffectViewStyleRegular`

旧系统没有完全相同的样式能力，因此用语义材质近似映射；UI 仍保留相同选项，但运行时允许安全降级。

### 三种模式的几何

所有尺寸都是窗口逻辑坐标：

| 模式 | 窗口 | 原生玻璃 frame | 圆角 |
| --- | --- | --- | --- |
| `compact` | `100×100` | `x=10, y=10, 80×80` | `28` |
| `quota` | `320×320` | `x=0, y=0, 320×320` | `40` |
| `stats` | `400×400` | `x=0, y=0, 400×400` | `40` |

前端窗口控制器完成尺寸和位置调整后，调用后端模式命令同步原生玻璃 frame。重复设置同一模式也要重新同步，以覆盖窗口恢复或系统缩放变化。

## 设置模型

### 玻璃透明度

继续使用 `glassTransparency: 10...90`。数值越高，视觉越透明。CSS 使用它计算背景 alpha；原生玻璃将它映射到 tint alpha。

### 效果强度

为了兼容已有配置和 CSS 回退，持久化字段仍保留 `glassBlurStrength: 0...60`，但设置 UI 不再展示连续滑块：

| UI | 持久化值 | 原生含义 |
| --- | --- | --- |
| 弱 | `20` | 较轻 tint / 较轻旧系统材质 |
| 中 | `40` | 默认 |
| 强 | `60` | 更明显 tint / 更强旧系统材质 |

读取旧的任意数值时按最近档位显示，不丢失用户现有配置。保存后写入对应标准值。

### 玻璃样式

新增向后兼容字段：

```text
glassStyle: clear | regular
```

旧配置缺少该字段时默认 `regular`。非法值在反序列化或标准化时回到默认值。

## 悬停和闲置行为

删除悬浮球 2 秒后自动添加 `quota-orb--idle` 的逻辑及对应 CSS。悬停仍触发展开，鼠标离开仍触发收起；卡片背景、透明度和模糊程度在这两个状态之间保持一致。

## 错误处理

- 原生玻璃应用结果通过现有 `glass-effect-status` 事件上报。
- 外观设置持久化成功但原生更新失败时，不让应用崩溃；CSS 回退继续显示。
- 模式同步命令失败时，前端窗口尺寸变更仍保留，下一次模式同步重试原生 frame。
- 所有原生 AppKit 操作在主线程通过 Tauri 的 WebView 回调完成。

## 验收标准

- 收起和两种展开状态都不再出现窗口大小的矩形底板。
- 三种模式原生玻璃严格匹配卡片 frame 和圆角。
- Hover 前后截图无透明度跳变。
- 设置中可调透明度、清透/标准样式、弱/中/强效果。
- 旧偏好文件可正常加载并补齐默认样式。
- macOS 26、旧 macOS 与 CSS 回退路径都有自动化契约测试。
- 前端测试、Rust 测试和 macOS release 构建全部通过。
