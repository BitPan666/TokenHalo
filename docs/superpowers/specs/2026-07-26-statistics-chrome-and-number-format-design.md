# 统计卡片统一与数字格式设计

## 目标

使本机 Token 统计卡片在视觉上与使用情况卡片一致，清楚呈现固定的统计范围，并以当前语言自然显示 Token 数量。

## 范围

- 两种卡片复用同一套 `CardChrome` 尺寸。统计卡片不得再覆盖标题、辅助文字、状态圆点、操作按钮、图标和操作间距的尺寸。
- 只有共享标题栏确实需要空间时才增加统计卡片宽度；不为容纳内容而缩小文字或操作控件。
- `day` 始终为 7 个桶（今天和此前 6 个本地自然日），`week` 始终为 12 个周桶，`month` 为当前自然年的 12 个月。
- 中文：小于 10,000 时显示普通数字；10,000 至小于 100,000,000 使用“万”；达到 100,000,000 使用“亿”。
- 英文：保持 `K`、`M`、`B` 缩写。两种语言最多保留两位小数，并统一用于主数字、明细、柱状图和柱状图提示。

## 设计

`TokenStatsCard` 根据现有语言偏好选择本地化格式化器。格式化器返回数值部分与单位部分，使主数字保留现有视觉层级：中文使用“万”或“亿”，英文使用 `K`、`M` 或 `B`。

统计卡片移除本地 `CardChrome` 覆盖规则，使标题栏继承使用情况卡片的字号、24 px 操作目标、13 px 图标和 3 px 操作间距。只有在共享操作栏确实需要空间时，外壳才可小幅增加宽度。

后端范围逻辑继续作为唯一数据来源。组件测试断言 7 / 12 根柱的数量，并覆盖各语言与阈值下的格式化结果。

## 验收条件

- 使用情况和统计卡片的 `CardChrome` 使用完全一致的 CSS 规则。
- 日、周图表分别恰好包含 7 和 12 根柱。
- 中文将 `5.25M` 显示为 `525 万`，达到 100,000,000 时使用“亿”；英文对应显示 `M` 或 `B`。
- 既有无障碍标签仍保留完整数值含义，并覆盖中英文测试。
